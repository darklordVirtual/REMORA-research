# REMORA artifact package

Committed, hash-checked evidence that the claim register
(`docs/assurance/claim_register_v1.yaml`) and the paper point at. Nothing in
this folder is regenerated on the fly; `scripts/check_claim_provenance.py`
verifies that every cited artifact exists and, for claim-bound JSON results,
carries a `.provenance.json` sidecar (pre-protocol artifacts are grandfathered
by id in `docs/assurance/claim_provenance_baseline.json`).

What the directories hold (as of 2026-08-26):

| Directory | Contents |
|---|---|
| `aromer/` | AROMER learning-layer evaluations: component ablation, external dataset evals, holdout episodes, intelligence snapshots |
| `audit_anchoring/` | Sample Merkle checkpoints for the audit-anchoring guide |
| `credibility-pack/` | Frozen reviewer pack: attestation, architecture overview, benchmark results (REM-021 handoff) |
| `cyber_evidence_v1/` | Vector payload for the cyber evidence layer |
| `demo/` | Static demo pages, the shadow-mode sample agent action log, and the what-if analysis of the `try` presets (`whatif_presets_v1.json`, regenerated by `scripts/generate_whatif_presets.py`) |
| `docker/` | Dockerfile for the reproduction environment |
| `figures/` | Paper and README figures |
| `governance-benchmark-pack/` | Self-contained governance benchmark bundle (frozen copy of NEGATIVE_RESULTS.md included) |
| `governance_intelligence/` | Governance-intelligence evaluation results with sidecar |
| `pilot-pack/` | What a shadow-pilot partner receives: README, event schema, evaluation worksheet |
| `posthoc/` | Post-hoc (non-claim) reanalyses, labelled as such |
| `sdk/` | Public API snapshots for `remora.sdk` (checked in CI) |
| `shadow_mode/` | Shadow-replay governance delta report and replay audit |
| `spec_intake/` | Spec-driven intake fidelity results |
| `supply-chain/` | npm audit snapshots |
| `use-cases/` | Use-case figures |
| `verify_protocols/` | Pre-registered VERIFY control-protocol rescoring |

Top-level JSON files are benchmark results and summaries referenced by
`docs/results_snapshot.md` (generated by `scripts/generate_results_snapshot.py`);
`bom.spdx.json` is the SBOM.

`./artifacts/reproduce.sh` regenerates the results snapshot, reruns the
statistical tests, checks claim consistency and runs the test suite. It does
not re-run benchmarks: the promoted results are frozen and change only under
`docs/assurance/rebenchmark_protocol_v1.md`.
