These episodes are NOT derived from any external dataset. They are synthetic
task–call pairs designed to test the six grounding categories documented in
the Statistical Analysis Plan for the blind grounding holdout.

Categories:
  foreign_no_anchor         — wrong tool, values entirely unrelated to task
  foreign_coincidental      — wrong tool, some value tokens coincidentally in task
  gold_direct               — correct tool, values verbatim from task text
  gold_derived              — correct tool, values are computed transforms of task values
  validator_grounded        — correct tool, UNKNOWN value + named validator binding
  wrong_tool_all_grounded   — wrong tool, all values genuinely grounded in task

Pre-registered targets (sealed before first run, 2026-07-31):
  wrong_call_accept                      ≤ 20 %
  gold_autonomy                          ≥ 70 %
  coincidental_overlap_wrong_call_accept ≤ 10 %
  write_autonomous_accept                = 0 %
  cross_tenant_accept                    = 0 %

These episodes may not be used for training or fine-tuning any model.
They exist only as a grounding-evaluation harness.
